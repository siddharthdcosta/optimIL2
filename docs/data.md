# Data

Survey of the data available for ionic liquid (IL) generation, as of 2026-11-10.

Nothing here has been imported into the repo yet. Numbers marked **checked** were
measured by us on the downloaded files with RDKit or by querying the source
directly. Numbers marked **reported** come from the papers and have not been
verified.

## Summary

| Quantity | Count |
|---|---|
| Real ILs with structures (SMILES) | 7,505 |
| Real ILs with at least one measured property | roughly 3,000–4,000 (exact count needs the ILThermo import) |
| Virtual IL pairs available to download | about 8.6 million |
| Unique cations across all sources | about 1.12 million |
| Unique anions across all sources | about 0.40 million |
| Public 3D structures of ILs | none found |

For comparison, FlowMol3 was trained on GEOM-Drugs: 243,480 unique molecules
and 5,741,535 3D conformers.

Main conclusions:

- Real ILs are scarce: about 7,500, which is 30× fewer than FlowMol3's
  training molecules.
- The large virtual sets are either low in diversity (ILPE) or mostly outside
  IL chemistry (PubChem ions).
- All 3D structures will have to be generated by us.
- Only ILThermo needs crawling. Everything else is a plain download.

### ILGen collected ILs

- The best available set of real IL structures. Built from ILThermo plus
  literature by the Jelfs group at Imperial College.
- 3 SMILES do not parse.
- Every entry is written as one cation plus one anion. 133 entries are
  therefore not charge-neutral and need their ion counts fixed.
- Cation families: imidazolium 1,257; quaternary ammonium 878; pyridinium 342;
  phosphonium 128; pyrrolidinium 97; piperidinium 63; sulfonium 43; protic
  ammonium 23; other 389.
- Known pairs are sparse: 7,505 out of 1.64 million possible pairings of the
  same ions (about 0.5%).

### NIST ILThermo v2

- The main source of measured properties.
- The JSON search endpoint returns the full index in about a minute.
  Fetching the values needs one more request per dataset (about 51,000).
- The index gives compound names and internal IDs only. SMILES need a
  separate name-to-structure step.
- 163,123 data points are for pure ILs. The rest are binary and ternary
  mixtures, which include ordinary solvents.

### IL Property Explorer (ILPE)

Built by attaching substituents from a fixed list to 9 cation cores, then
pairing every cation with 38 anions. SMILES are included.

Synthesizability (checked):

- Synthetic accessibility score: median 3.0, 99th percentile 3.5 (1 is easy,
  10 is hard).
- No cations contain groups that are unstable next to a positive charge.
- So nearly all entries could plausibly be made.

Problems (checked):

- **Low diversity.** 219,296 cations share only 228 ring frameworks. The real
  set has 387 frameworks in 3,220 cations. 82% of ILPE cations are
  tetraalkylammonium.
- **Poor coverage of real ILs.** Only 344 of 3,220 real cations and 28 of 509
  real anions appear. 586 of the 7,505 real ILs are in ILPE. 44% of real
  cations have no ILPE cation with similarity above 0.4.
- **One malformed anion.** `OC(C(F)(F)F)[CH-]C(C(F)(F)F)O` looks like a
  mis-drawn hexafluoroacetylacetonate. All 219k pairs containing it (2.6%)
  should be dropped.
- **Many entries are probably solids.** ILPE predicts 0.03% melt above
  100 °C. Among measured salts, 39% do.
- **Property values are rough.** Melting point averages ±55 °C uncertainty
  and is capped to −25 to 155 °C. Viscosity uncertainty is about 50%. Density
  (±25 kg/m³) is the only trustworthy one. COSMO-RS values exist for 53 rows.
- **Unstable pairs.** 92,820 pairs combine an imidazolium cation with a basic
  anion. ILPE's own model predicts 5.1% of entries decompose below 200 °C.
- **Missing chemistry.** No protic ILs and no newer anions such as FSI.

Diversity comparison (checked):

| | ILPE cations | Real IL cations | PubChem cations (50k sample) |
|---|---|---|---|
| Count | 219,296 | 3,220 | 50,000 |
| Ring frameworks | 228 | 387 | 26,102 |
| Share of most common framework | 41% | 23% | 6% |
| Mean pairwise similarity | 0.275 | 0.118 | 0.093 |

Verdict: usable as a small, evenly sampled supplement. Not suitable as the
main training set, and its property values should not be used as labels.

### PubChem ions

All structures are valid with the correct charge sign, but most are drug-like
molecules that carry a charge, not IL ions.

Cations, 20,000 sampled (checked):

| | PubChem | Real IL |
|---|---|---|
| Protonated amine | 37.6% | 9.8% |
| Alkylated aromatic N⁺ | 22.0% | 53.4% |
| Quaternary N⁺ | 14.2% | 23.7% |
| Mean rings per ion | 2.66 | 1.16 |
| Mean amide groups per ion | 0.53 | 0.03 |
| Mean heavy atoms | 22.6 | 16.2 |

Anions, 20,000 sampled (checked):

| | PubChem | Real IL |
|---|---|---|
| Carboxylate | 52.9% | 32.6% |
| Sulfonate or sulfate | 4.4% | 15.7% |
| Borate | 0.0% | 13.6% |
| Contains fluorine | 14% | 28% |
| Net charge beyond ±1 | 9.2% | 0.6% |

Closeness to real IL ions (checked on 5,000 sampled):

- 74% of cations and 60% of anions have no real IL ion with similarity
  above 0.3.
- At a similarity cutoff of 0.4, about 9% of cations (roughly 80k) and 12% of
  anions (roughly 47k) remain.
- At 0.5, about 34k cations and 14k anions remain.
- Only 191 real IL cations and 13 real IL anions are present in the pool.

Verdict: a filtered slice gives tens of thousands of IL-like ions. The raw
pool is not usable, and it lacks borates and fluorinated anions.

### AIonopedia synthetic set

- The 2.8 million systems are not released. Only the generation script is
  public.
- The script pairs ions at random and labels them with computed descriptors.
  Nothing checks that the pairs are real ILs.

## 3D data

- No public 3D conformer dataset for ILs was found. The only IL-specific set
  seen is a 48-ion-pair DFT benchmark.
- Candidate general sources, not yet verified: OMol25 (large DFT dataset said
  to include electrolytes and ILs), the Crystallography Open Database
  (experimental salt crystal structures), and SPICE (includes ion pairs).

## Planned import steps

1. Define the target distribution from the cleaned 7,505 real ILs: allowed
   elements, charge, size range, and whether protic ILs are included.
2. Decide each source in or out, recording license and what it contributes.
3. Write one download script per source in `scripts/data/`, saving untouched
   files to `data/raw/`.
4. Standardise to one schema: canonical SMILES, separate ions, correct ion
   counts, a source column, and one deduplication key.
5. Gate every source on an in-distribution check against the real IL set.
6. Keep measured properties in a separate table linked by IL key.
7. Fix the train/test split before adding virtual data, holding out whole
   ions.
8. Generate 3D structures last: ion conformers, then ion pairs.

## Open issues

- The ILGen repos have no license. Ask the authors before redistributing
  their files.
- The count of real ILs with measured properties is an estimate until
  ILThermo is imported and its names are converted to SMILES.
- OMol25, the Crystallography Open Database and SPICE have not been inspected.
